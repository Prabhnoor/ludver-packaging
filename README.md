# Ludver Packaging

Simple company website for ludver.com: custom packaging, warehousing supplies, and machinery.

GitHub Pages publishes the main branch from the root. Contact buttons open a Gmail compose draft; they do not send messages. The enquiry recipient is set in site-config.js, with matching HTML fallback links in index.html.

The logo is the existing Ludver Packaging logo. The product image is an original AI-generated generic packaging concept, not a photograph of a customer order. No competitor assets are used.

The client machinery proposal is maintained separately in Prabhnoor/ludver-machinery at machinery.ludver.com. Do not copy private proposal source into this repository.
